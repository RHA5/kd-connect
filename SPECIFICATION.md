# KD CONNECT — АРХИТЕКТУРА И СПЕЦИФИКАЦИЯ (v0.10.6)

Десктопный компаньон для автоматического сбора статистики матчей в игре **Hunt: Showdown 1896** и мгновенной синхронизации с веб-сервисом **KD Metrika** (kdmetrika.ru).

---

## 1. БЕЗОПАСНОСТЬ (100% ANTI-CHEAT SAFE)
* **Принцип нулевого вмешательства:** программа не внедряется в память игры (No DLL injection, No API Hooking, No ReadProcessMemory).
* **Пассивный бинарный парсинг:** потокобезопасное чтение (`rb`) стандартных логов игры и видеодрайвера в режиме без блокировки (`FileShare.ReadWrite`), буферизация неполных строк и декодирование UTF-8 (`errors='replace'`).
* **Абсолютная безопасность EAC:** нулевой риск бана от Crytek и Easy Anti-Cheat.

---

## 2. ИСТОЧНИКИ ДАННЫХ И СИГНАЛЫ
Программа непрерывно отслеживает два файла:
1. **NVIDIA GfeSDK Log:**  
   `%LOCALAPPDATA%\NVIDIA Corporation\GfeSDK\HuntGame_*.log` (динамический подхват при перезапуске оверлея).
2. **Hunt Game Log:**  
   `<SteamApps>\common\Hunt Showdown 1896\user\Game.log` (быстрое авто-обнаружение по фиксированным локальным дискам).

### Матрица боевых событий и тайминги
* **Убийство врага (Kill):** сигнал драйвера `Posted Request HLSetVideo` с буферизацией 1.2с для подтверждения отсутствия смерти игрока.
* **Смерть охотника (Death):** спаривание сигнала `HLSetVideo` с `death/StateMachine` в Game.log в окне до 2.7с.
* **Обоюдные размены (Mutual Trades):** дельта между убийством и гибелью <= 1.0с.
* **Посмертные фраги (Post-mortem Kills):** фиксация фрагов от ловушек/яда/горения после гибели.
* **Спектатор / Наблюдение:** блокировка ложных срабатываний при открытом экране смерти (`death_screen_open == True`).
* **Инъекция времени (Deterministic Clock):** поддержка внешней временной шкалы (`clock_fn`) для детерминированного воспроизведения в офлайн-тестах.

## 3. СЕТЕВАЯ СИНХРОНИЗАЦИЯ И ОТКАЗОУСТОЙЧИВОСТЬ
* **Персистентная дисковая очередь:** файл `%APPDATA%\KDConnect\pending_matches.json` сохраняет неотправленные матчи при сбоях сети с атомарной записью (`.tmp` + `os.replace`).
* **Авто-восстановление незавершенного матча:** файл `%APPDATA%\KDConnect\match_recovery.json` очищается строго после успешной постановки матча в сеть; при ошибке запись сохраняется (`[RECOVERY:KEEP]`).
* **Обработка конфликтов:**
  * `session_mismatch`: сервер сообщает о закрытии сессии — отклоненный матч удаляется, остальные остаются в очереди.
  * `manual_conflict`: сервер зафиксировал ручную правку — на клиенте блокируются новые импульсы до решения конфликта.
* **Атомарная конфигурация:** `config.json` сохраняется через временный файл с резервной копией `config.json.bak` и авто-восстановлением при повреждении JSON.
* **Перехват сбоев (Crash Log):** `%APPDATA%\KDConnect\crash.log` фиксирует фатальные исключения через `sys.excepthook`, `threading.excepthook` и `faulthandler`.

## 4. ИНТЕРФЕЙС И ВСТРОЕННЫЙ БРАУЗЕР (pywebview)
* **Локальная сборка UI:** автономный `preview.html` со встроенным бандлом Tailwind CSS v3 (без внешних CDN).
* **Безопасность CSP:** `default-src 'self'`, `img-src 'self' data:`, `connect-src 'self' ... https://kdmetrika.ru`.
* **Диалоги подтверждения сессии:**
  * При завершении сессии во время боя: модальное окно подтверждения выхода.
  * При наличии неотправленных матчей: выбор «Повторить отправку / Завершить без них».
* **Ограничение внешних переходов:** `open_external_url` разрешает только HTTPS к доверенным доменам (`kdmetrika.ru`, `127.0.0.1`, `t.me`).

---

## 5. АВТООБНОВЛЕНИЕ И ДИСТРИБУЦИЯ
* **Защищенный манифест:** `https://kdmetrika.ru/downloads/version.json` с контрольными суммами `sha256_setup` и `sha256_exe`.
* **Безопасность обновления:** полный запрет запуска обновления при активном матче или сессии; жесткий отказ при несовпадении SHA-256.
* **Отвязанный установщик:** фоновый запуск установщика с задержкой и мгновенным `os._exit(0)` приложения.
* **Инсталлятор Inno Setup:** `KD-Connect.iss` с мьютексом `Local\KDConnectSingleInstanceMutex`, мягким закрытием `CloseApplications=yes` и сохранением пользовательских настроек в AppData.
* **Конвейер сборки:** PowerShell-скрипт `tools/build_release.ps1` автоматизирует цикл от компиляции CSS до обновления хэшей в `version.json`.
