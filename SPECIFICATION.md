# KD CONNECT — АРХИТЕКТУРА И ПЛАН РАЗРАБОТКИ

Десктопный компаньон для автоматического сбора статистики матчей в игре **Hunt: Showdown 1896** и мгновенной синхронизации с веб-сервисом **KD Metrika** (kdmetrika.ru).

---

## 1. БЕЗОПАСНОСТЬ (100% ANTI-CHEAT SAFE)
* **Принцип нулевого вмешательства:** программа не внедряется в память игры (No DLL injection, No API Hooking, No ReadProcessMemory).
* **Пассивный парсинг:** чтение стандартных текстовых логов игры и видеодрайвера в режиме `FileShare.ReadWrite`.
* Никаких рисков бана от Easy Anti-Cheat (EAC).

---

## 2. ИСТОЧНИКИ ДАННЫХ И СИГНАЛЫ
Программа непрерывно отслеживает два файла:
1. **NVIDIA GfeSDK Log:**  
   `%LOCALAPPDATA%\NVIDIA Corporation\GfeSDK\HuntGame_*.log`
2. **Hunt Game Log:**  
   `<SteamApps>\common\Hunt Showdown 1896\user\Game.log`

### Матрица боевых событий
| Событие в игре | Сигнал NVIDIA Log | Сигнал Game.log | Временное окно | Итог в KD Connect |
| :--- | :--- | :--- | :--- | :--- |
| **Убийство врага (Kill)** | `Posted Request HLSetVideo` | *Отсутствует* | > 400 мс без смерти | **+1 Убийство** (шлет импульс на сайт) |
| **Мульти-килл (взрыв)** | Несколько `Posted Request HLSetVideo` подряд | *Отсутствует* | До 1000 мс | **+N Убийств** (по числу запросов) |
| **Смерть охотника (Death)** | `Posted Request HLSetVideo` | `Starting UI state machine 'death/StateMachine'` | Одновременно (0–400 мс) | **+1 Смерть** (шлет импульс на сайт) |

### Границы матча и статусы
* **Вход в матч:** строка `[HuntSession] PrepareLevel` и переход в `eLS_Game`.
* **Выход из матча:** строка `[HuntSession] Client_OnDisconnect (reasonType='MissionRequested')`.
* **Фильтрация режимов:**
  * Учитываются: `BountyHuntLobby` (Охота за наградой), `BountyClashLobby` (Схватка за награду).
  * Игнорируются: `QuickplayLobby` (Спасшаяся душа), `ShootingRangeLobby` / `levels/shooting` (Стрельбище).

### Обработка вылетов и реконнектов
* Если процесс `HuntGame.exe` завершился аварийно (краш), запускается таймер ожидания **15 минут**.
* Если игрок перезашел в игру в течение этого окна и сервер вернул сессию — текущий матч продолжается без разрыва статистики.

## 3. СИСТЕМА ЛОГИРОВАНИЯ И ТИКЕТОВ
* **Кольцевой буфер (ротация):** локальный лог `tracker.log` хранит историю последних **10 сессий** (или до 3 МБ). Старые записи затираются автоматически. При перезапуске приложения данные предыдущего сеанса не теряются.
* **Отправка тикета в один клик:** кнопка *«Отправить отчет об ошибке на сервер»* отправляет POST-запрос с логом на эндпоинт `/api/tracker/report`. Сервер сохраняет тикет в Supabase с привязкой к профилю игрока.

---

## 4. ИНТЕГРАЦИЯ С САЙТОМ (KDMETRIKA.RU)
* **Аутентификация:** личный секретный токен (`sync_token`), генерируемый в настройках профиля (`/settings`).
* **Ролевая модель:** доступ к функциям авто-трекера открыт только пользователям с флагом `role = 'TESTER'`. Обычные пользователи видят классический сайт.
* **API эндпоинты:**
  * `POST https://kdmetrika.ru/api/tracker/pulse` — отправка импульсов матчей и событий.
  * `POST https://kdmetrika.ru/api/tracker/report` — отправка отчетов об ошибках (тикеты).

## 5. ДИЗАЙН И UX ПРИЛОЖЕНИЯ (KD CONNECT)
* **Размер виджета:** компактный (380 x 510 px), темная монохромная тема, сворачивание на стандартную панель задач Windows.
* **Режим ожидания (до игры):**
  * Проверка 3 систем (NVIDIA, Game.log с ручным выбором папки, токен профиля).
  * Кнопка *«Проверить системы»*.
* **Режим активной сессии (в бою):**
  * Полная очистка экрана от служебных проверок.
  * Пульсирующий зеленый статус: *«Сессия активна. Идет автоматический сбор статистики»*.
  * Крупная кнопка: *«Открыть мою статистику на kdmetrika.ru →»*.
* **Экран настроек и помощи (шестеренка):**
  * Привязка токена `sync_token`.
  * Кнопка отправки тикета на сервер.
  * Пошаговая инструкция и подсказки (Alt+Z для NVIDIA, выбор папки для Game.log).
  * Версия программы и проверка обновлений.
