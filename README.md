# KD Connect

Официальный десктопный клиент автоматического трекинга для веб-сервиса **[KD Metrika](https://kdmetrika.ru)**.

Приложение автоматически фиксирует матчи, убийства, смерти и обоюдные размены в **Hunt: Showdown 1896** без ручного ввода статистики.

---

## Безопасность и Easy Anti-Cheat (EAC)

**KD Connect на 100% безопасен и не нарушает правила Crytek и Easy Anti-Cheat:**
- **Только чтение локальных логов:** Приложение анализирует исключительно текстовые файлы, создаваемые игрой (`user/Game.log`) и оверлеем NVIDIA (`GfeSDK/HuntGame_*.log`). Чтение выполняется в бинарном режиме (`rb`) без блокировки файлов.
- **Нулевое вмешательство:** 0 внедрений в память процесса (`0 memory injection`), 0 хуков, 0 модификаций файлов игры.
- **Открытый исходный код:** Проект полностью прозрачен, каждый пользователь может проверить код и собрать исполняемый файл самостоятельно.

---

## Основные возможности

- **Автоматический трекинг матчей:** Определение боевых карт (*Mammon's Gulch / Creek*, *Stillwater Bayou / Cemetery*, *Lawson Delta*, *DeSalle / CivilWar*) и режимов (*Bounty Hunt*, *Bounty Clash*, *Soul Survivor*). Игнорирование стрельбища и меню.
- **Подсчет киллов и смертей:** Высокая точность учета с поддержкой обоюдных разменов (*Mutual Trades*).
- **Синхронизация с профилем:** Привязка по одноразовому токену синхронизации к [kdmetrika.ru](https://kdmetrika.ru). Персистентная дисковая очередь неотправленных матчей (`pending_matches.json`) и авто-восстановление после сбоев.
- **Контроль статуса NVIDIA Overlay:** Мгновенная диагностика готовности оверлея к сбору хайлайтов.
- **Безопасное автообновление:** Проверка обновлений через защищенный API `https://kdmetrika.ru/downloads/version.json` со сверкой контрольных сумм SHA-256 (`sha256_setup`, `sha256_exe`), блокировкой обновления во время боя или сессии и мягким закрытием приложения.

## Требования

- Windows 10 / 11 (64-bit)
- Видеокарта NVIDIA с установленным **NVIDIA App** или **GeForce Experience** (с включенным внутриигровым оверлеем)
- Установленная игра **Hunt: Showdown 1896** в Steam
- Аккаунт на сервисе **[KD Metrika](https://kdmetrika.ru)**

## Сборка из исходников

### 1. Установка окружения
```bash
# Клонирование репозитория (основной GitHub или зеркало GitFlic)
git clone https://github.com/RHA5/kd-connect.git
# или: git clone https://gitflic.ru/project/kd-metrika/kd-connect.git
cd kd-connect

# Установка Python-зависимостей
pip install -r requirements.txt
```

### 2. Запуск в режиме разработки
```bash
python main.py
```

> [!IMPORTANT]
> **Правило сборки CSS:** После любых изменений в интерфейсе `preview.html` необходимо пересобрать стили перед запуском или компиляцией:
> ```bash
> npx -y tailwindcss@3 -i ./input.css -o ./dist/output.css --minify
> ```

### 3. Автоматизированная сборка релиза
Для полной конвейерной сборки (Tailwind v3 -> PyInstaller -> Inno Setup -> SHA-256 -> публикация):
```powershell
powershell -ExecutionPolicy Bypass -File tools/build_release.ps1
```

Скрипт автоматически:
1. Компилирует Tailwind CSS v3 и встраивает его в `preview.html`.
2. Собирает независимый исполняемый файл `dist/KD-Connect.exe` через PyInstaller.
3. Собирает установщик `installer/KD-Connect-Setup-v0.12.1.exe` через Inno Setup.
4. Вычисляет контрольные суммы SHA-256 (`sha256_exe`, `sha256_setup`).
5. Копирует артефакты в каталог загрузок и обновляет манифест `version.json`.
