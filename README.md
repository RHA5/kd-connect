# KD Connect

Официальный десктопный клиент автоматического трекинга для веб-сервиса **[KD Metrika](https://kdmetrika.ru)**.

Приложение автоматически фиксирует матчи, убийства, смерти и обоюдные размены в **Hunt: Showdown 1896** без ручного ввода статистики.

---

## Безопасность и Easy Anti-Cheat (EAC)

**KD Connect на 100% безопасен и не нарушает правила Crytek и Easy Anti-Cheat:**
- **Только чтение локальных логов:** Приложение анализирует исключительно текстовые файлы, создаваемые игрой (`user/Game.log`) и оверлеем NVIDIA (`GfeSDK/HuntGame_*.log`).
- **Нулевое вмешательство:** 0 внедрений в память процесса (`0 memory injection`), 0 хуков, 0 модификаций файлов игры.
- **Открытый исходный код:** Проект полностью прозрачен, каждый пользователь может проверить код и собрать исполняемый файл самостоятельно.

---

## Основные возможности

- **Автоматический трекинг матчей:** Определение боевых карт (*Mammon's Gulch / Creek*, *Stillwater Bayou / Cemetery*, *Lawson Delta*, *DeSalle / CivilWar*) и режимов (*Bounty Hunt*, *Bounty Clash*, *Soul Survivor*). Игнорирование стрельбища и меню.
- **Подсчет киллов и смертей:** Высокая точность учета с поддержкой обоюдных разменов (*Mutual Trades*).
- **Синхронизация с профилем:** Привязка по одноразовому токену синхронизации к [kdmetrika.ru](https://kdmetrika.ru).
- **Контроль статуса NVIDIA Overlay:** Мгновенная диагностика готовности оверлея к сбору хайлайтов.
- **Автоматическое обновление:** Встроенная проверка релизов через GitHub Releases и бесшовное обновление приложения в один клик.

---

## Требования

- Windows 10 / 11 (64-bit)
- Видеокарта NVIDIA с установленным **NVIDIA App** или **GeForce Experience** (с включенным внутриигровым оверлеем)
- Установленная игра **Hunt: Showdown 1896** в Steam
- Аккаунт на сервисе **[KD Metrika](https://kdmetrika.ru)**

## Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/RHA5/kd-connect.git
cd kd-connect

# Установка зависимостей
pip install pywebview psutil pyinstaller

# Запуск в режиме разработки
python main.py

# Сборка единого .exe файла
pyinstaller --noconfirm --clean "KD Connect.spec"
```

Собранный исполняемый файл появится в папке `dist/KD-Connect.exe`.
